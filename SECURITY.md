# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to
[support@tumerit.com](mailto:support@tumerit.com) with the subject
"Tethered security report". Do not include vulnerability details in public GitHub
issues, discussions, or pull requests before coordinated disclosure.

Include the affected Tethered version or repository commit, macOS version,
reproduction steps, expected and observed behavior, and potential impact. For
integration issues, include the client and integration versions. Share a minimal
proof of concept where possible, and remove passwords, tokens, personal data,
and other secrets from logs or screenshots.

Reports may cover the Tethered application, its helper and local bridges,
repository integrations, or the release and update process. Please test only on
systems you own or have permission to assess, and avoid accessing other people's
data or disrupting their systems.

## Versions and fixes

Please use the latest available Tethered release and integration versions.
Security fixes are delivered through new releases; fixes for older versions are
not guaranteed. If you find an issue in an older version, include that version in
your report even if you cannot reproduce it on the latest release.

## Coordinated disclosure

Please allow time to investigate and address a report before publishing details.
We will coordinate next steps and disclosure timing through the reporting email
thread. This policy does not promise a response deadline or a monetary reward.
